COLUMN B · DEFINITIONS

AA structural pattern that encapsulates state machine transitions to alter class behavior dynamically at runtime without conditional statements.
BAn automated, continuous check executed in a CI/CD pipeline to verify that code changes do not violate architectural constraints, performance budgets, or isolation rules.
CAn immutable design artifact (e.g. color hex codes, spacing scale) stored in a single source of truth that translates visual branding directly into executable code variables across platforms.
DAn anti-pattern where domain objects contain data structures with getters/setters but zero business logic, forcing business rules to scatter into service/helper layers.
EAn architectural tactic that isolates execution resource pools (e.g. thread pools, process memory) so failure or saturation in one dependency cannot exhaust resources for others.
FA resiliency pattern that intercepts outbound calls to a failing remote dependency, failing fast when error thresholds are crossed.
GA deployment mechanism that routes 10% of production traffic to a newly deployed service version to verify error rates before full rollout.
